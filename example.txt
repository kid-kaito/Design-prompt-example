You are a senior frontend architect and product designer.



Design and implement a modern production-grade UI for a software platform.



## Product Context



The application is a:

Scheduler application that will be used to automate testing workflow of a wafer inspection machine. A Workflow (a particular type of testing) would have different components. Each component would require some inputs (configuration) taken from the user using forms. Based on the configuartion of the components, the UI will make gRPC calls to the backend service. I want the UI to be pulgable i.e. the specification of the gRPC calls would be handeled by some module that can provide abstact interface to the UI so that the behaviour can be changed later in that module. The complete specification for UI is given below. The scheduler would have many parts other than the desktop UI. But for now only desktop UI is to be focused.
